# CarSharing Report with SQL Queries

## Project Overview
This project analyses hourly car-sharing demand data collected between January 2017 and August 2018. It uses Google Sheets for data preparation and SQLite for database management and SQL-based business analysis.

## Project Objectives
- Clean missing temperature values.
- Categorise temperature as Cold, Mild, or Hot.
- Create temperature and weather codes.
- Extract time features from timestamps.
- Organise the data into four related tables.
- Use SQL queries to analyse car demand during 2017.

## Project Files
- `CarSharing_df.csv` — Main demand table.
- `temperature.csv` — Temperature categories and codes.
- `weather.csv` — Weather conditions and codes.
- `time.csv` — Timestamp and calendar features.
- `CarSharing_Transformed_Tables.xlsx` — Workbook containing the four tables.
- `carsharing.db` — SQLite database.
- `CarSharing_SQL_Queries.sql` — Commented SQL queries.
- `CarSharing_Report.docx` — Project report.
